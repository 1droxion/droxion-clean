Get in touch

Contact Droxion

FIVE is an independent browser word game from Droxion. If you have feedback about a puzzle, a word accepted or rejected by the dictionary, or a problem with gameplay, please include the device, browser, and the steps to reproduce the issue.

Technical feedback

You can report a public technical issue using the project's GitHub issue tracker. Please don't include passwords, personal contact information or private game details in public reports.

General inquiries

We're preparing a dedicated public support contact for FIVE. In the meantime, the issue tracker is available for technical feedback.

Play and share

Play today's puzzle and share the colored result grid if you want to invite a friend without revealing the word.
